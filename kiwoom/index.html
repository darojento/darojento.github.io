키움 종목분석

장 마감 후 확정된 일봉으로, 내가 정한 조건에 맞는 종목을 찾아 보고서로 정리하는 개인용 Android 앱입니다.

개인용무료주문 기능 없음
투자 권유가 아닙니다 이 앱은 정보를 정리해 보여 줄 뿐이며 매수·매도를 권하지 않습니다. 투자 판단과 그 결과의 책임은 사용자 본인에게 있습니다.

주요 기능

  • 장 마감 후 분석: 사용자 본인의 키움 REST API 키로 시세(종목 정보·일봉)를 조회하고, 장 마감 후 확정된 일봉만 사용합니다.
  • 조건 검색: 사용자가 직접 정한 조건(전략)으로 종목을 걸러 냅니다.
  • 보고서 생성: 검색 결과를 날짜별 HTML 보고서로 만들어 휴대폰에 저장하고 앱 안에서 봅니다.
  • Google Drive 백업: 사용자가 연결한 경우에만, 보고서와 백업 파일을 사용자 본인 Google Drive의 「키움종목분석」 폴더에 올립니다. 앱이 만든 파일에만 접근하는 drive.file 권한만 사용합니다.

하지 않는 것

  • 매매 주문, 계좌 조회, 잔고 조회 기능이 없습니다.
  • 종목 추천이나 투자 자문을 하지 않습니다.
  • 광고, 사용 통계 수집, 오류 보고(크래시 수집) 도구를 넣지 않았습니다.
  • 개발자 서버가 없습니다. 데이터는 휴대폰과 사용자 본인 Drive에만 있습니다.

누구를 위한 앱인가요

개발자 본인이 자기 휴대폰에서 쓰기 위해 만든 개인용 앱이며, 앱 마켓에 배포하지 않습니다. 이 앱은 키움증권 및 Google과 제휴하거나 그들로부터 승인받은 앱이 아닙니다.
