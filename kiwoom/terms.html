투자 권유가 아닙니다. 앱이 보여 주는 결과는 정보 제공용이며, 투자 판단과 그 결과의 책임은 사용자 본인에게 있습니다.

1. 서비스 성격

  • 「키움 종목분석」(이하 "앱")은 개발자가 본인 휴대폰에서 쓰기 위해 만든 개인용 앱이며, 무상으로 제공됩니다.
  • 앱은 사용자가 정한 조건으로 종목을 걸러 보고서를 만드는 도구입니다. 매매 주문 기능이 없고, 종목 추천이나 투자 자문을 하지 않습니다.

2. 투자 판단의 책임

앱의 검색 결과와 보고서는 투자 권유나 매매 신호가 아닙니다. 이를 참고해 내린 투자 결정과 그로 인한 손익은 전적으로 사용자 본인에게 있으며, 개발자는 책임지지 않습니다.

3. 데이터 정확성

  • 앱은 사용자 본인의 키움 REST API 키로 받은 시세(장 마감 후 확정 일봉)를 바탕으로 계산합니다.
  • 원천 데이터의 오류·지연·누락, 통신 장애, 계산 방식의 한계로 결과가 실제와 다를 수 있습니다. 개발자는 데이터와 결과의 정확성·완전성·적시성을 보증하지 않습니다.
  • 앱은 "있는 그대로" 제공되며, 특정 목적에 맞는다는 보증을 하지 않습니다.

4. 사용자의 책임

  • 키움 API 키와 Google 계정은 사용자 본인 것이어야 하며, 키움증권과 Google의 약관을 지켜야 합니다.
  • API 사용량 제한이나 키 관리 소홀로 생긴 문제는 사용자가 책임집니다.

5. 제3자와의 관계

앱은 키움증권 및 Google과 제휴하거나 그들로부터 승인·후원받은 앱이 아닌 개인 앱입니다. 키움증권과 Google은 각 회사의 상표이며, 앱은 각 회사가 공개한 API를 사용할 뿐입니다.

6. 개인정보

개인정보와 Google 사용자 데이터 처리는 개인정보처리방침을 따릅니다.

7. 변경

약관을 바꾸면 이 페이지에 새 내용과 시행일을 게시합니다. 바뀐 약관이 게시된 뒤에도 앱을 계속 쓰면 변경에 동의한 것으로 봅니다.
