개인정보처리방침

시행일: 2026-10-20 · 적용 대상: Android 앱 「키움 종목분석」(패키지 com.jjlim.kiwoomanalyzer)

요약

  • Google Drive 권한은 drive.file(이 앱이 만든 파일만) 하나만 요청합니다.
  • 보고서와 백업은 사용자 본인 Google Drive에만 저장합니다.
  • Google 사용자 데이터를 개발자나 제3자에게 전송·공유·판매하지 않으며, 광고나 분석에 쓰지 않습니다.
  • 개발자 서버가 없고, 광고·사용 통계·크래시 수집 도구가 들어 있지 않습니다.
  • 키움 API 키는 휴대폰 안에서 암호화해 저장합니다.

1. 앱이 통신하는 곳

앱은 아래 목적지와만 통신합니다. 이 밖에 개발자가 운영하는 서버나 다른 제3자 서버로 데이터를 보내지 않습니다.

목적지목적보내는 정보
api.kiwoom.com
mockapi.kiwoom.com(모의투자 선택 시)		키움 REST API 접근 토큰 발급·폐기, 종목 정보·일봉 시세 조회사용자가 입력한 키움 App Key·Secret Key(토큰 발급 시), 조회할 종목 코드와 날짜
www.googleapis.com(Google Drive API v3)앱 폴더 만들기, 보고서·백업 파일 올리기, 앱이 만든 파일 목록 보기·내려받기, 보관 기간이 지난 앱 백업 파일을 휴지통으로 옮기기앱이 만든 보고서·백업 파일과 그 이름, Google이 발급한 접근 토큰
Google Play 서비스(기기에 설치된 Google 구성요소)Google 계정 권한 동의와 접근 토큰 발급Google이 처리하며, 앱은 결과로 받은 토큰과 화면 표시용 계정 이메일만 사용합니다.

키움 API 사용은 키움증권의 약관과 개인정보처리방침을, Google 계정·Drive 사용은 Google의 약관과 개인정보처리방침을 따릅니다.

2. Google 사용자 데이터의 접근·사용·저장·공유

접근하는 데이터

  • 요청 범위: https://www.googleapis.com/auth/drive.file 하나뿐입니다. 이 범위로는 이 앱이 만들었거나 사용자가 앱에서 직접 고른 파일에만 접근할 수 있으며, 사용자의 다른 Drive 파일은 보거나 읽을 수 없습니다.
  • 연결된 Google 계정의 이메일 주소: 설정 화면에 "어느 계정에 연결됐는지" 보여 주는 용도로만 쓰며, 저장하지 않습니다.

사용 방법

  • 사용자 Drive에 「키움종목분석」 폴더(테스트 모드는 「키움종목분석_TEST」)를 만들고, 그 안에 날짜별 HTML 보고서와 백업 파일(zip, manifest, 전략 설정 json)을 올립니다.
  • 사용자가 복구를 요청하면 앱이 올린 백업 목록을 읽고 고른 파일을 내려받아 휴대폰 데이터를 되살립니다.
  • 보관 개수를 넘은 오래된 앱 백업 파일을 Drive 휴지통으로 옮깁니다.

저장

  • 보고서·백업 파일은 사용자 본인 Google Drive에만 저장됩니다. 개발자는 이 파일에 접근할 수 없습니다.
  • Google 접근 토큰은 기기에 저장하지 않고, Drive 요청 직전마다 Google Play 서비스에서 새로 받아 메모리에서만 씁니다.

공유

  • Google 사용자 데이터를 개발자나 어떤 제3자에게도 전송·공유·판매하지 않습니다.
  • 광고, 광고 타기팅, 사용 분석, 신용 평가, AI 모델 학습에 쓰지 않습니다.
  • 사람이 이 데이터를 읽는 일은 없습니다. 예외는 사용자 본인이 요청하거나 동의한 경우, 보안 문제 조사, 법령 준수에 필요한 경우뿐입니다.

Google API 서비스 사용자 데이터 정책 준수

키움 종목분석이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API Services User Data Policy를 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

3. 휴대폰에 저장하는 데이터

  • 키움 API 키(App Key·Secret Key)와 서버 선택: Android Keystore의 AES-256/GCM 키로 암호화해 앱 전용 저장소에만 둡니다. Android 자동 백업과 기기 이전 대상에서 제외했고, Drive 백업에도 넣지 않습니다.
  • 분석 데이터(앱 내부 데이터베이스): 종목 정보·일봉 시세, 사용자가 정한 조건(전략), 검색 결과, 실행 기록, Drive 업로드 대기 목록, 백업 기록.
  • 파일: 날짜별 보고서(HTML·JSON), 가장 최근 백업 1개.
  • 앱 설정: 데이터 모드(실제/테스트), 알림 상태 등.

앱의 Android 자동 백업은 꺼 두었습니다. 사용자가 보고서 화면의 「공유」를 누르면 Android 공유 창이 열리고, 사용자가 고른 앱으로만 해당 보고서 파일이 전달됩니다.

4. 수집하지 않는 정보

  • 이름, 전화번호, 위치, 연락처, 계좌번호, 잔고, 거래 내역을 수집하지 않습니다. 앱에는 매매 주문·계좌 조회 기능이 없습니다.
  • 광고 ID, 사용 통계, 크래시 보고를 수집하지 않습니다. 앱에는 Firebase·Crashlytics 등 분석·크래시 수집 SDK가 없습니다.

5. 권한 철회와 데이터 삭제

Google Drive 권한 철회

  1. Google 계정에 접속합니다.
  2. 보안 → 타사 앱 및 서비스(타사 액세스)로 갑니다.
  3. 「키움 종목분석」을 선택하고 액세스 권한 삭제를 누릅니다.

철회하면 앱은 더 이상 Drive에 파일을 올리거나 읽을 수 없습니다. 이미 올라간 파일은 사용자 Drive에 그대로 남습니다.

데이터 삭제

  • Drive의 파일: Google Drive에서 「키움종목분석」(및 「키움종목분석_TEST」) 폴더를 삭제하고 휴지통을 비웁니다.
  • 휴대폰의 데이터: Android 설정 → 앱 → 키움 종목분석 → 저장공간 → 데이터 삭제, 또는 앱을 삭제합니다. 암호화된 키움 API 키도 함께 지워집니다.
  • 개발자 서버가 없으므로 개발자 쪽에 따로 남는 데이터는 없습니다.

6. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 변경

이 방침을 바꾸면 이 페이지에 새 내용과 시행일을 게시합니다. Google 사용자 데이터를 쓰는 방식이 달라지면 미리 앱이나 이 페이지에 알리고, 필요하면 다시 동의를 받습니다.
